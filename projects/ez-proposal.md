# EZ제안

제안 업무와 발표 준비를 지원하는 AI 도구를 개발하고 있습니다. RFP 분석, 조견표 생성, 제안서·발표장표 초안 생성, 챗봇, PT코칭 기능의 초기 버전을 만들었고, 현재는 이를 프로젝트로 발전시켜 고도화하는 중입니다.

**역할:** 주요 기능 초기 개발 및 고도화 참여  
**상태:** 개발·고도화 및 실제 사업 활용 중

## 시작한 이유

AICC 사업을 수행하고 제안 작성에 참여하면서, 요구사항을 확인하고 이를 문서로 옮기는 작업을 반복했습니다. 같은 RFP를 보더라도 분석 결과, 조견표, 제안서, 발표자료 사이에서 내용이 어긋날 수 있었습니다. 이 과정을 연결해 제안 업무를 지원하는 도구를 만들고자 했습니다.

## 개발한 기능

| 기능 | 지원하는 업무 |
| --- | --- |
| RFP 분석 | 요구사항과 평가·작성 기준 확인 |
| 조견표 생성 | 요구사항과 제안 내용의 대응 관계 정리 |
| 제안서 초안 생성 | 분석과 전략을 바탕으로 작성 시작점 제공 |
| 발표장표 초안 생성 | 발표 내용 구성과 슬라이드 제작 지원 |
| 챗봇 | 자료를 찾아보고 업무 관련 질문에 답변 |
| PT코칭 | 발표 준비를 위한 분석과 피드백 리포트 제공 |

## 고도화하면서 다룬 문제

발표장표에서는 내용을 템플릿에 맞추는 과정에서 항목이 빠지거나 같은 문구가 반복되는 문제가 있었습니다. 세 단계짜리 절차를 네 칸 템플릿에 배치하면 빈칸이 생기고, 빈칸을 채우려다 원문에 없던 설명이 들어갈 수도 있었습니다.

장표 내용의 관계와 항목 수를 기준으로 표현 방식을 고르고, 결과를 검수하는 방향으로 개선하고 있습니다. 아키텍처, 처리 흐름, 조직도는 서로 다른 관계를 나타내므로 구분해서 다룹니다. 장표와 발표 대본도 같은 내용을 설명하는지 함께 확인합니다.

PT코칭에서는 발표 내용과 대본에 기반한 피드백을 중심으로 다룹니다. 자세·시선 등 비언어적 요소는 발표자가 참고할 수 있는 보조 정보로 구분합니다.

## 활용과 피드백

- **6개 사업**에서 EZ제안을 활용해 제안 업무를 자동화하는 중입니다.
- **사내 대회 3회**에서 참가자 **100명 이상**에게 PT코칭 리포트를 제공했습니다.

2026년 9월 기준 설문 피드백은 **67건**입니다.

| 설문 항목 | 응답 결과 |
| --- | --- |
| 만족 또는 매우 만족 | 100% |
| 발표 역량 향상에 도움이 됨 | 94% |
| 분석 결과가 본인 체감과 일치함 | 88% |

설문 결과는 사용자가 느낀 만족도와 도움 정도를 나타냅니다. 모델 정확도나 발표 점수의 객관적 상승률을 의미하지는 않습니다.

## 현재 작업

실제 제안 업무에서 쓰면서 생성 결과의 일관성과 검수 과정을 개선하고 있습니다. 산출물 초안이 업무에 도움이 되려면, 요구사항과 전략의 연결이 유지되고 사용자가 내용을 확인·수정할 수 있어야 한다고 보고 있습니다.

- AI PT 셀프 코칭
