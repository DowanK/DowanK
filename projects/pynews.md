# 파이뉴스

AICC 관련 기사를 수집·정리하고 메일로 공유하는 업무를 Python으로 자동화한 팀 프로젝트입니다. **본부 혁신 개발 프로젝트에 개발자로 참여**했으며, 사내 팀에 매일 관련 뉴스를 공유하는 업무에 활용했습니다.

**기간:** 2023.06.01–2023.10.01  
**역할:** 개발자 참여

## 자동화한 업무

관심 키워드와 기간에 맞는 기사를 찾고, 중복된 기사를 걸러내고, 내용을 요약해 메일에 정리하는 과정을 구현했습니다.

1. 키워드·기간을 기준으로 기사 검색 및 본문 수집
2. 기사 제목과 본문 유사도를 활용한 중복 제거
3. 기사 요약 생성과 발송할 기사 선택
4. 링크와 요약을 포함한 HTML 메일 구성
5. 수신자에게 메일 발송

## 팀에서 구현한 기능

| 영역 | 사용 기술·구현 |
| --- | --- |
| 기사 수집 | Python, Requests, BeautifulSoup |
| 중복 처리 | 제목 유사도, TF-IDF 및 코사인 유사도 |
| 요약 | LLM API를 통한 기사 요약 |
| 사용자 화면 | Streamlit |
| 메일 발송 | SMTP, HTML 메일 생성 |

기사를 확인하고 선택하거나 요약을 다시 생성할 수 있는 화면도 구성했습니다.

## 활용

팀에 AICC 관련 뉴스를 매일 공유하는 업무에 적용했습니다. 반복 업무를 자동화하는 프로젝트에 직접 참여하며, 수집부터 결과 전달까지 하나의 흐름으로 연결하는 개발 경험을 쌓았습니다.
