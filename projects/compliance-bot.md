# 컴플라이언스 이행봇

프로젝트를 수행하며 확인해야 하는 법령·판례·사내 규정을 검색하고 답변에 활용하는 RAG 챗봇을 개발했습니다. **2024년 1차 개발로 사내 부문 대회 1등을 수상**했고, 이후 앱 형태의 고도화를 진행했습니다.

| 단계 | 기간 | 결과 |
| --- | --- | --- |
| 1차 챗봇 개발 | 2024.03.01–2024.12.01 | 사내 부문 대회 1등 수상 |
| 2차 앱 고도화 | 2025.10.21–2025.11.30 | 개발 진행 후 예산 사유로 종료 |

## 시작한 이유

SI 프로젝트를 수행하면서 하도급, 계약, 안전, 윤리 등 여러 영역의 법령과 회사 규정을 확인해야 했습니다. 상황에 맞는 자료를 찾고 관련 내용을 함께 살펴볼 수 있도록, 법령과 판례를 답변의 근거로 활용하는 챗봇을 만들었습니다.

## 구현 내용

법령과 판례 문서를 나누어 처리하고, 질문과 관련된 자료를 검색해 답변에 사용했습니다. 의미 기반 검색을 위한 FAISS와 키워드 검색을 위한 BM25를 결합했으며, 한국어 텍스트 처리에는 Kiwi를 사용했습니다.

Streamlit으로 질문·답변 화면을 구성하고, 답변에 활용하는 사례 자료를 추가·삭제할 수 있는 관리 기능을 구현했습니다. 답변 생성에는 LLM API를 사용했습니다.

| 영역 | 사용 기술·구현 |
| --- | --- |
| 개발 언어·화면 | Python, Streamlit |
| 검색 | FAISS, BM25, EnsembleRetriever |
| 텍스트 처리 | 한국어 형태소 처리, 법령·사례별 문서 분할 |
| 챗봇 구성 | LangChain, LangGraph, LLM API |
| 자료 관리 | 사례 추가·삭제 및 검색 인덱스 갱신 |

## 개발하며 다룬 문제

개발 기록에는 여러 사용자가 접속했을 때 응답이 섞이는 문제, 문서 분할 방식에 따른 검색 결과 차이, 연속적인 답변 처리 문제가 남아 있습니다. 사용자별 대화 처리와 병렬·비동기 처리 방식을 점검하고, 법령과 사례의 문서 분할을 조정했습니다.

검색 결과가 있어도 질문의 상황에 맞는 근거인지 확인하는 과정이 필요했습니다. 검색과 답변 생성을 함께 조정하며 근거 자료를 활용하는 방식을 개선했습니다.

## 앱 고도화

2025년에는 프로젝트 이행을 지원하는 챗봇을 앱으로 제공하는 고도화를 진행했습니다. 2차 개발은 예산 사유로 종료됐습니다.
